引入“ [第二大脑](/zh-cn/posts/benefits-of-a-personal-knowledge-management-system/) ”的概念——一个 [个人知识管理](/zh-cn/posts/digital-decluttering-for-information-overload/)（PKM）系统，旨在充当您最有价值的想法、见解和信息的外部、集中式数字存储库。通过 [学习](/zh-cn/posts/how-to-remember-what-you-read-effectively/) 如何构建 [第二大脑](/zh-cn/posts/tiago-forte-building-a-second-brain-review/)，您可以释放大脑带宽，减少认知负担，并将您所消费的信息系统地转化为切实的创意产出。

这份综合指南将引导您了解构建高效数字 [第二大脑](/zh-cn/posts/second-brain-for-boosting-creativity/) 的理念、方法论和分步过程。

## 什么是第二大脑？

由生产力专家 Tiago Forte 提出并推广，第二大脑是一个值得信赖的数字系统，用于收集、组织和检索您的知识。把它想象成一个个人图书馆、一个数字笔记本和一个协作伙伴的结合体。

与通常随意而无序的传统 [笔记](/zh-cn/posts/digital-garden-vs-second-brain-difference/) 不同，第二大脑是高度结构化和有目的的。它不仅仅是囤积信息；它是关于创建一个动态环境，让想法可以互动、随着时间的推移而复合，并最终用于您的个人和专业项目。

### 第二大脑的益处

建立个人知识管理系统需要投入时间和精力，但其复利回报是巨大的：

1.  **减少认知负担：** 通过将事实、任务和想法卸载到值得信赖的外部系统，您可以消除忘记重要事情的潜在焦虑。
2.  **增强创造力：** 创造力很大程度上是关于连接看似不相关的点。第二大脑会浮现旧笔记，并将其与新想法并置，激发偶然的见解。
3.  **加快内容产出：** 无论您是 [撰写](/zh-cn/posts/atomic-notes-writing-guide/) 论文、准备演示文稿还是创业，您都将永远不会从一张白纸开始。您只需从您已经整理的丰富材料中提取即可。
4.  **改善学习和记忆：** 捕捉和综合信息的过程迫使您深入参与材料，从而提高您的实际理解和记忆。

## 核心框架：CODE 方法论

要了解如何有效地构建第二大脑，您必须掌握其底层操作系统。最广泛采用的 PKM 框架是 CODE 方法论，它代表着捕捉（Capture）、组织（Organize）、提炼（Distill）和表达（Express）。

### 1. 捕捉：保留共鸣的内容
第一步是养成捕捉信息的习惯。然而，目标不是剪辑您阅读的每篇文章或记录每次会议。捕捉的黄金法则是 **只保存引起共鸣的内容**。

问自己：
* 这是否激励了我？
* 这对当前项目有用吗？
* 这是否挑战了我现有的信念？

如果答案是肯定的，就捕捉它。您的捕捉 [工具](/zh-cn/posts/roam-research-vs-obsidian-comparison/) 应该毫无摩擦。无论您使用网页剪辑工具、移动快速捕捉应用程序还是语音备忘录工具，捕捉一个想法所需的时间都应少于三秒。

### 2. 组织：为可操作性而保存
一旦信息被捕获，就需要进行组织。初学者最大的错误是按主题或类别进行组织（例如，将有关营销策略的笔记放入通用的“营销”文件夹中）。这种方法使得在您实际需要信息时很难找到它。

相反，请为 **可操作性** 进行组织。您接下来将在哪里使用此信息？这个原则完美地体现在 **PARA 方法** 中，它是第二大脑的组织骨干：

*   **项目（Projects）：** 您当前正在进行的、有特定截止日期或结果的短期工作或生活任务（例如，“设计第三季度营销活动”、“计划日本度假”）。
*   **领域（Areas）：** 您希望长期管理但没有特定结束日期的长期责任（例如，“健康与健身”、“财务”、“产品管理”）。
*   **资源（Resources）：** 具有持续效用的主题或兴趣（例如，“架构设计模式”、“健康食谱”、“SEO 最佳实践”）。
*   **存档（Archives）：** 来自其他三个类别的非活跃项目。当项目完成后，将其移至存档。它使您的工作区保持整洁，同时保留知识以备将来使用。

### 3. 提炼：寻找精髓
捕获的信息很少能以原始形式使用。一篇 5,000 字的文章过于密集，无法快速 [回顾](/zh-cn/posts/scrintal-vs-heptabase-for-visual-note-taking/)。提炼是提取笔记核心信息的过程，以便您未来的自己可以一目了然。

这里使用的技术称为 **渐进式总结（Progressive Summarization）**。它涉及随着时间的推移分层高亮：
*   **第 1 层：** 您捕获的原始文本。
*   **第 2 层：** 文本中主要观点和关键句子的加粗。
*   **第 3 层：** 粗体文本中最关键部分的突出显示（或下划线）。
*   **第 4 层：** 在笔记顶部用您自己的话写一份简短的、项目符号形式的执行摘要。

通过渐进式总结，您可以为未来的自己设计笔记，让您在几秒钟内掌握复杂主题的精髓。

### 4. 表达：展示您的工作
第二大脑的最终目的不仅仅是收集信息，而是利用这些信息在现实世界中创造价值。“表达”阶段是将您提炼的知识转化为切实的产出：撰写博客文章、进行推介、设计产品或录制播客。

因为您已经捕获、组织和提炼了相关信息，所以表达阶段变成了组装的练习，而不是从头开始创建。您本质上是在组装您预先制作好的知识乐高积木。

## 为您的第二大脑选择合适的工具

您的第二大脑需要一个数字家园。虽然该方法论与软件无关，但选择一个与您的工作流程相符的工具至关重要。以下是领先的笔记和 PKM 应用程序类别：

### 架构师应用程序 (Notion, Coda, Anytype)
这些应用程序结构高度化、由数据库驱动且可无限定制。如果您想构建自定义仪表板、跟踪项目状态并将任务管理与笔记相结合，它们是绝佳的选择。
*   **最适合：** 喜欢设计系统、管理复杂项目和 [可视化组织](/zh-cn/posts/steps-to-building-a-second-brain/) 的人。

### 园丁应用程序 (Obsidian, Roam Research, Logseq)
这些工具依赖于双向链接，允许您无缝连接笔记。您不是使用严格的文件夹，而是构建一个“知识图谱”，模仿人脑自然关联概念的方式。
*   **最适合：** 研究人员、作家、学者以及专注于综合复杂思想和发现意想不到的联系的人。

### 图书管理员应用程序 (Evernote, Apple Notes, Microsoft OneNote)
这些是传统、熟悉的笔记应用程序。它们擅长快速捕捉、富媒体存储（如 PDF 和图像）以及强大的搜索功能。
*   **最适合：** 初学者，主要想要一个快速、可靠的数字文件柜而无需陡峭学习曲线的人。

**专家建议：** 不要陷入“工具摩擦”。从您已经使用和理解的应用程序开始。您的系统结构远比支持它的软件更重要。

## 构建第二大脑的分步指南

准备好从理论转向实践了吗？这里有一份实用、分步的路线图，教您如何在周末设置您的个人知识管理系统。

### 步骤 1：建立您的数字收件箱
选择一个工具作为您的通用收件箱。这可以是 iOS 上的 Drafts 等应用程序，Apple Notes 中的特定文件夹，或 Readwise 等统一网页剪辑工具。训练自己立即将每个想法、链接和任务倾倒到此收件箱中。在捕获时无需担心组织问题。

### 步骤 2：实施 PARA 结构
打开您的主要笔记应用程序，并在根级别创建四个文件夹：
1. 项目（Projects）
2. 领域（Areas）
3. 资源（Resources）
4. 存档（Archives）

在“项目”文件夹内，为您当前正在进行的 3-5 个活跃项目创建子文件夹。根据您当前的生活职责，对“领域”做同样的操作。抵制过度构建文件夹结构的冲动；让它随着您添加笔记而有机增长。

### 步骤 3：进行数字大脑清扫
设定一个 30 分钟的计时器。写下目前占据您所有思绪的一切。哪些项目停滞不前？哪些文章您一直想读？淋浴时哪些想法不断涌入您的脑海？将它们全部捕获到您的收件箱中，作为单独的原始笔记。

### 步骤 4：整理和提炼
浏览您新填充的收件箱。对于每条笔记，问自己：*现在最适合采取行动的是什么？* 将笔记移动到相应的项目、领域或资源文件夹。如果笔记特别密集，花两分钟应用渐进式总结的第一层，加粗关键要点。

### 5：安排每周回顾
第二大脑需要定期维护，以防止其变成数字垃圾场。安排一个 30 分钟的时间段，在周五下午或周日晚上进行“每周回顾”。在此期间：
*   通过将新笔记路由到 PARA 结构来清空您的收件箱。
*   归档本周完成的任何项目。
*   为下周创建新的项目文件夹。
*   简要回顾您现有的笔记，以激发当前挑战的想法。

## 常见的陷阱

在您开始构建第二大脑时，请注意这些常见的陷阱，它们让许多 PKM 爱好者功亏一篑：

*   **收藏家谬误：** 这是一种错误的信念，认为仅仅保存一篇文章就等同于阅读或理解它。不要成为数字囤积者。少捕获，但更深入地参与您捕获的内容。
*   **过度优化您的系统：** 花 10 小时配置一个带有复杂公式的 Notion 仪表板，而不是实际做笔记，这是一种拖延症。从简单开始。
*   **强行连接：** 在 Obsidian 等链接思维应用程序中，初学者常常试图将每个单词都链接到另一条笔记。仅当它们代表有意义的逻辑连接时才创建链接。
*   **忘记输出：** 如果您花费数月时间构建一个庞大的知识数据库，但从未发表过文章、启动过项目或分享过见解，那么您的第二大脑仅仅是一个虚荣项目。始终优化表达。

## 高级概念：Zettelkasten 与第二大脑

当您深入研究个人知识管理时，您将不可避免地遇到 *Zettelkasten* 一词。由社会学家 Niklas Luhmann 创建，Zettelkasten（卡片盒）方法是一种高度学术化的笔记方法，它依赖于在物理索引卡上编写原子化的、单一想法的笔记，并使用字母数字代码手动链接它们。

虽然 Zettelkasten 对于密集的学术写作非常强大，但第二大脑方法论通常更宽容、更全面，更适合现代快节奏的数字工作。然而，许多高级用户将两者融合，利用 PARA 方法进行高级组织（项目和领域），同时在“资源”文件夹中使用 Zettelkasten 原则（原子笔记和双向链接）来发展复杂、相互关联的想法。

## 知识管理的终身旅程

学习如何构建第二大脑不是一个一次性的项目；它是您与信息互动方式的根本性转变。这是从被动的内容消费者到主动的知识策展者和创造者的转变。

一开始，您的系统可能会显得稀疏。但随着时间的推移，在数月和数年中，当您捕捉到您最好的想法、提炼您的阅读内容并组织您的项目时，您的第二大脑将跨越一个关键的阈值。它将从一个简单的存储系统演变为一个智能伙伴——一个数字化的思维延伸，它将不断以其深度让您惊叹，帮助您产出最佳作品，并最终让您自由地 [专注于](/zh-cn/posts/managing-digital-information-overload-tips/) 最重要的事情。

今天就开始吧。选择一个应用程序，设置您的 PARA 文件夹，并捕捉您的第一条笔记。您未来的自己会感谢您。

## 常见问题

### CODE 框架代表什么？

CODE 是第二大脑的核心操作系统：捕捉（Capture，保存引起共鸣的内容）、组织（Organize，为可操作性而保存）、提炼（Distill，寻找精髓）和表达（Express，将知识转化为切实的产出或项目）。

### PARA 方法如何组织信息？

PARA 将所有数字文件组织到四个顶级文件夹中：项目（Projects，有截止日期的活跃目标）、领域（Areas，长期责任）、资源（Resources，持续感兴趣的主题）和存档（Archives，来自其他三个类别的非活跃项目）。

### 什么是“渐进式总结”？

渐进式总结是一种分层提炼笔记的技术。您首先将笔记中最好的部分加粗，然后将这些粗体部分中最好的部分高亮，最后在顶部写一个 3 句话的总结，以确保笔记可以快速浏览。

### 我应该按主题还是按项目组织我的笔记？

第二大脑方法论优先按项目组织。按主题（如“心理学”）组织信息在您实际工作时很难找到。按项目（如“启动新应用程序”）组织可确保相关知识准确地位于您需要执行的位置。

### 哪些工具最适合第二大脑？

“最佳”工具取决于您的风格：Notion 非常适合项目管理和数据库；Obsidian 和 Logseq 非常适合网络思维和双向链接；Evernote 或 Apple Notes 非常适合简单、快速的数字归档。

在当今高度互联、信息丰富的世界中，人脑不断受到数据轰炸。从富有洞察力的播客和发人深省的文章，到重要的工作邮件和随机的灵感火花，我们每天都在以前所未有的数量消费信息。然而，尽管信息如此丰富，我们却常常发现自己很难回忆起昨天的一个绝妙想法，或者找不到几个月前保存的 [重要研究](/zh-cn/posts/progressive-summarization-workflow-for-deep-research-papers/)。

问题不在于信息缺乏；而在于我们依赖生物大脑来存储所有信息。正如作者 David Allen 曾说过的：“你的大脑是用来产生想法的，而不是用来记住它们的。”

引入“ [第二大脑](/zh-cn/posts/benefits-of-a-personal-knowledge-management-system/) ”的概念——一个 [个人知识管理](/zh-cn/posts/digital-decluttering-for-information-overload/)（PKM）系统，旨在充当您最有价值的想法、见解和信息的外部、集中式数字存储库。通过 [学习](/zh-cn/posts/how-to-remember-what-you-read-effectively/) 如何构建 [第二大脑](/zh-cn/posts/tiago-forte-building-a-second-brain-review/)，您可以释放大脑带宽，减少认知负担，并将您所消费的信息系统地转化为切实的创意产出。

这份综合指南将引导您了解构建高效数字 [第二大脑](/zh-cn/posts/second-brain-for-boosting-creativity/) 的理念、方法论和分步过程。

## 什么是第二大脑？

由生产力专家 Tiago Forte 提出并推广，第二大脑是一个值得信赖的数字系统，用于收集、组织和检索您的知识。把它想象成一个个人图书馆、一个数字笔记本和一个协作伙伴的结合体。

与通常随意而无序的传统 [笔记](/zh-cn/posts/digital-garden-vs-second-brain-difference/) 不同，第二大脑是高度结构化和有目的的。它不仅仅是囤积信息；它是关于创建一个动态环境，让想法可以互动、随着时间的推移而复合，并最终用于您的个人和专业项目。

### 第二大脑的益处

建立个人知识管理系统需要投入时间和精力，但其复利回报是巨大的：

1.  **减少认知负担：** 通过将事实、任务和想法卸载到值得信赖的外部系统，您可以消除忘记重要事情的潜在焦虑。
2.  **增强创造力：** 创造力很大程度上是关于连接看似不相关的点。第二大脑会浮现旧笔记，并将其与新想法并置，激发偶然的见解。
3.  **加快内容产出：** 无论您是 [撰写](/zh-cn/posts/atomic-notes-writing-guide/) 论文、准备演示文稿还是创业，您都将永远不会从一张白纸开始。您只需从您已经整理的丰富材料中提取即可。
4.  **改善学习和记忆：** 捕捉和综合信息的过程迫使您深入参与材料，从而提高您的实际理解和记忆。

## 核心框架：CODE 方法论

要了解如何有效地构建第二大脑，您必须掌握其底层操作系统。最广泛采用的 PKM 框架是 CODE 方法论，它代表着捕捉（Capture）、组织（Organize）、提炼（Distill）和表达（Express）。

### 1. 捕捉：保留共鸣的内容
第一步是养成捕捉信息的习惯。然而，目标不是剪辑您阅读的每篇文章或记录每次会议。捕捉的黄金法则是 **只保存引起共鸣的内容**。

问自己：
* 这是否激励了我？
* 这对当前项目有用吗？
* 这是否挑战了我现有的信念？

如果答案是肯定的，就捕捉它。您的捕捉 [工具](/zh-cn/posts/roam-research-vs-obsidian-comparison/) 应该毫无摩擦。无论您使用网页剪辑工具、移动快速捕捉应用程序还是语音备忘录工具，捕捉一个想法所需的时间都应少于三秒。

### 2. 组织：为可操作性而保存
一旦信息被捕获，就需要进行组织。初学者最大的错误是按主题或类别进行组织（例如，将有关营销策略的笔记放入通用的“营销”文件夹中）。这种方法使得在您实际需要信息时很难找到它。

相反，请为 **可操作性** 进行组织。您接下来将在哪里使用此信息？这个原则完美地体现在 **PARA 方法** 中，它是第二大脑的组织骨干：

*   **项目（Projects）：** 您当前正在进行的、有特定截止日期或结果的短期工作或生活任务（例如，“设计第三季度营销活动”、“计划日本度假”）。
*   **领域（Areas）：** 您希望长期管理但没有特定结束日期的长期责任（例如，“健康与健身”、“财务”、“产品管理”）。
*   **资源（Resources）：** 具有持续效用的主题或兴趣（例如，“架构设计模式”、“健康食谱”、“SEO 最佳实践”）。
*   **存档（Archives）：** 来自其他三个类别的非活跃项目。当项目完成后，将其移至存档。它使您的工作区保持整洁，同时保留知识以备将来使用。

### 3. 提炼：寻找精髓
捕获的信息很少能以原始形式使用。一篇 5,000 字的文章过于密集，无法快速 [回顾](/zh-cn/posts/scrintal-vs-heptabase-for-visual-note-taking/)。提炼是提取笔记核心信息的过程，以便您未来的自己可以一目了然。

这里使用的技术称为 **渐进式总结（Progressive Summarization）**。它涉及随着时间的推移分层高亮：
*   **第 1 层：** 您捕获的原始文本。
*   **第 2 层：** 文本中主要观点和关键句子的加粗。
*   **第 3 层：** 粗体文本中最关键部分的突出显示（或下划线）。
*   **第 4 层：** 在笔记顶部用您自己的话写一份简短的、项目符号形式的执行摘要。

通过渐进式总结，您可以为未来的自己设计笔记，让您在几秒钟内掌握复杂主题的精髓。

### 4. 表达：展示您的工作
第二大脑的最终目的不仅仅是收集信息，而是利用这些信息在现实世界中创造价值。“表达”阶段是将您提炼的知识转化为切实的产出：撰写博客文章、进行推介、设计产品或录制播客。

因为您已经捕获、组织和提炼了相关信息，所以表达阶段变成了组装的练习，而不是从头开始创建。您本质上是在组装您预先制作好的知识乐高积木。

## 为您的第二大脑选择合适的工具

您的第二大脑需要一个数字家园。虽然该方法论与软件无关，但选择一个与您的工作流程相符的工具至关重要。以下是领先的笔记和 PKM 应用程序类别：

### 架构师应用程序 (Notion, Coda, Anytype)
这些应用程序结构高度化、由数据库驱动且可无限定制。如果您想构建自定义仪表板、跟踪项目状态并将任务管理与笔记相结合，它们是绝佳的选择。
*   **最适合：** 喜欢设计系统、管理复杂项目和 [可视化组织](/zh-cn/posts/steps-to-building-a-second-brain/) 的人。

### 园丁应用程序 (Obsidian, Roam Research, Logseq)
这些工具依赖于双向链接，允许您无缝连接笔记。您不是使用严格的文件夹，而是构建一个“知识图谱”，模仿人脑自然关联概念的方式。
*   **最适合：** 研究人员、作家、学者以及专注于综合复杂思想和发现意想不到的联系的人。

### 图书管理员应用程序 (Evernote, Apple Notes, Microsoft OneNote)
这些是传统、熟悉的笔记应用程序。它们擅长快速捕捉、富媒体存储（如 PDF 和图像）以及强大的搜索功能。
*   **最适合：** 初学者，主要想要一个快速、可靠的数字文件柜而无需陡峭学习曲线的人。

**专家建议：** 不要陷入“工具摩擦”。从您已经使用和理解的应用程序开始。您的系统结构远比支持它的软件更重要。

## 构建第二大脑的分步指南

准备好从理论转向实践了吗？这里有一份实用、分步的路线图，教您如何在周末设置您的个人知识管理系统。

### 步骤 1：建立您的数字收件箱
选择一个工具作为您的通用收件箱。这可以是 iOS 上的 Drafts 等应用程序，Apple Notes 中的特定文件夹，或 Readwise 等统一网页剪辑工具。训练自己立即将每个想法、链接和任务倾倒到此收件箱中。在捕获时无需担心组织问题。

### 步骤 2：实施 PARA 结构
打开您的主要笔记应用程序，并在根级别创建四个文件夹：
1. 项目（Projects）
2. 领域（Areas）
3. 资源（Resources）
4. 存档（Archives）

在“项目”文件夹内，为您当前正在进行的 3-5 个活跃项目创建子文件夹。根据您当前的生活职责，对“领域”做同样的操作。抵制过度构建文件夹结构的冲动；让它随着您添加笔记而有机增长。

### 步骤 3：进行数字大脑清扫
设定一个 30 分钟的计时器。写下目前占据您所有思绪的一切。哪些项目停滞不前？哪些文章您一直想读？淋浴时哪些想法不断涌入您的脑海？将它们全部捕获到您的收件箱中，作为单独的原始笔记。

### 步骤 4：整理和提炼
浏览您新填充的收件箱。对于每条笔记，问自己：*现在最适合采取行动的是什么？* 将笔记移动到相应的项目、领域或资源文件夹。如果笔记特别密集，花两分钟应用渐进式总结的第一层，加粗关键要点。

### 步骤 5：安排每周回顾
第二大脑需要定期维护，以防止其变成数字垃圾场。安排一个 30 分钟的时间段，在周五下午或周日晚上进行“每周回顾”。在此期间：
*   通过将新笔记路由到 PARA 结构来清空您的收件箱。
*   归档本周完成的任何项目。
*   为下周创建新的项目文件夹。
*   简要回顾您现有的笔记，以激发当前挑战的想法。

## 常见的陷阱

在您开始构建第二大脑时，请注意这些常见的陷阱，它们让许多 PKM 爱好者功亏一篑：

*   **收藏家谬误：** 这是一种错误的信念，认为仅仅保存一篇文章就等同于阅读或理解它。不要成为数字囤积者。少捕获，但更深入地参与您捕获的内容。
*   **过度优化您的系统：** 花 10 小时配置一个带有复杂公式的 Notion 仪表板，而不是实际做笔记，这是一种拖延症。从简单开始。
*   **强行连接：** 在 Obsidian 等链接思维应用程序中，初学者常常试图将每个单词都链接到另一条笔记。仅当它们代表有意义的逻辑连接时才创建链接。
*   **忘记输出：** 如果您花费数月时间构建一个庞大的知识数据库，但从未发表过文章、启动过项目或分享过见解，那么您的第二大脑仅仅是一个虚荣项目。始终优化表达。

## 高级概念：Zettelkasten 与第二大脑

当您深入研究个人知识管理时，您将不可避免地遇到 *Zettelkasten* 一词。由社会学家 Niklas Luhmann 创建，Zettelkasten（卡片盒）方法是一种高度学术化的笔记方法，它依赖于在物理索引卡上编写原子化的、单一想法的笔记，并使用字母数字代码手动链接它们。

虽然 Zettelkasten 对于密集的学术写作非常强大，但第二大脑方法论通常更宽容、更全面，更适合现代快节奏的数字工作。然而，许多高级用户将两者融合，利用 PARA 方法进行高级组织（项目和领域），同时在“资源”文件夹中使用 Zettelkasten 原则（原子笔记和双向链接）来发展复杂、相互关联的想法。

## 知识管理的终身旅程

学习如何构建第二大脑不是一个一次性的项目；它是您与信息互动方式的根本性转变。这是从被动的内容消费者到主动的知识策展者和创造者的转变。

一开始，您的系统可能会显得稀疏。但随着时间的推移，在数月和数年中，当您捕捉到您最好的想法、提炼您的阅读内容并组织您的项目时，您的第二大脑将跨越一个关键的阈值。它将从一个简单的存储系统演变为一个智能伙伴——一个数字化的思维延伸，它将不断以其深度让您惊叹，帮助您产出最佳作品，并最终让您自由地 [专注于](/zh-cn/posts/managing-digital-information-overload-tips/) 最重要的事情。

今天就开始吧。选择一个应用程序，设置您的 PARA 文件夹，并捕捉您的第一条笔记。您未来的自己会感谢您。

## 常见问题

### CODE 框架代表什么？

CODE 是第二大脑的核心操作系统：捕捉（Capture，保存引起共鸣的内容）、组织（Organize，为可操作性而保存）、提炼（Distill，寻找精髓）和表达（Express，将知识转化为切实的产出或项目）。

### PARA 方法如何组织信息？

PARA 将所有数字文件组织到四个顶级文件夹中：项目（Projects，有截止日期的活跃目标）、领域（Areas，长期责任）、资源（Resources，持续感兴趣的主题）和存档（Archives，来自其他三个类别的非活跃项目）。

### 什么是“渐进式总结”？

渐进式总结是一种分层提炼笔记的技术。您首先将笔记中最好的部分加粗，然后将这些粗体部分中最好的部分高亮，最后在顶部写一个 3 句话的总结，以确保笔记可以快速浏览。

### 我应该按主题还是按项目组织我的笔记？

第二大脑方法论优先按项目组织。按主题（如“心理学”）组织信息在您实际工作时很难找到。按项目（如“启动新应用程序”）组织可确保相关知识准确地位于您需要执行的位置。

### 哪些工具最适合第二大脑？

“最佳”工具取决于您的风格：Notion 非常适合项目管理和数据库；Obsidian 和 Logseq 非常适合网络思维和双向链接；Evernote 或 Apple Notes 非常适合简单、快速的数字归档。
