### 三个核心目录

这是 Zettelkasten 的核心。Permanent Notes (通常称为 Zettels) 是原子化的、精心编写的想法，它们是从您的 fleeting notes 和 literature notes 中处理而来的。每个 permanent note 都应该包含一个单一的想法，用您自己的话编写，并与其他的 permanent notes 高度链接。

Zettelkasten 中的标签应该代表广泛的主题或完成状态，而不是超特定的关键词。笔记之间的链接起着特定关键词的作用。

## 常见问题

### 我需要为 Obsidian Zettelkasten starter kit 付费吗？
不需要。虽然一些创建者在 Patreon 或 Gumroad 等平台上提供高级的、高度定制的 vault，但 GitHub 和官方 Obsidian 社区论坛上有大量优秀的免费 starter kit 可用。Zettelkasten 的基本机制可以轻松通过免费的开源配置实现。

### 下载的 vault 会覆盖我现有的 Obsidian 笔记吗？
不会，除非您将 ZIP 文件直接解压到您现有的 vault 目录中。Obsidian 将每个文件夹视为一个独立的 vault。您可以在不同的窗口中同时打开旧 vault 和新的 starter kit，从而逐步将旧笔记迁移到新结构中。

### 如果创建者发布了新版本，我如何更新 starter kit？
Starter kit 不是软件应用程序；它们只是包含文本文件和设置的文件夹。如果创建者发布更新，您不能简单地“点击更新”。您需要下载新的 ZIP 文件，查看他们对模板或 `.obsidian` 设置文件夹所做的更改，然后手动将这些更改应用到您现有的活动 vault，以避免覆盖您自己的笔记。

### 我应该使用文件夹还是标签来组织我的 permanent notes？
在一个纯粹的 Zettelkasten 系统中，您应该完全依赖链接和标签。所有 permanent notes 理想情况下都应该位于一个单一的、扁平的文件夹中。文件夹是僵化的，并且只允许笔记存在于一个位置。链接和标签允许笔记同时存在于多个上下文中，这是网络化思想的核心哲学。

### 为什么有些 starter kit 使用随机数字作为文件名？
这是 Luhmann ID 方法（例如，`202605071430.md`），由 Zettelkasten 的发明者创建。它确保每个文件都具有永久唯一的标识符，防止在您创建两个标题相似的笔记时发生文件名冲突。虽然有效，但许多现代 Obsidian 用户更喜欢自然语言标题（例如，`Obsidian scaling limitations.md`），以在 Graph View 中获得更好的可读性，并依赖 Obsidian 的内部数据库来管理链接。

此文件夹存放您对外部资源的总结。无论是书籍、科学论文、文章还是 YouTube 视频，Literature Note 都充当您的书目记录。一个强大的 starter kit 将包含此文件夹的特定模板，其中包含 YAML frontmatter，用于 `Author`、`Source URL`、`Date Read` 和 `Tags` 等属性。

**02 - Permanent Notes (The Slip-box)**
这是 Zettelkasten 的核心。Permanent Notes (通常称为 Zettels) 是原子化的、精心编写的想法，它们是从您的 fleeting notes 和 literature notes 中处理而来的。每个 permanent note 都应该包含一个单一的想法，用您自己的话编写，并与其他的 permanent notes 高度链接。

**98 - Templates**

**99 - Attachments**
图像、PDF 和音频文件可能会很快淹没 vault。Starter kit 应该预配置为将所有粘贴的图像和拖放的文件直接发送到此中心存储库，使您的主要工作目录严格只包含文本文件。

## 分步：安装和初始化您下载的 Vault

一旦您找到并下载了包含 starter kit 的 ZIP 文件，安装过程需要几个特定步骤，以确保 Obsidian 正确识别配置文件。

### 第 1 步：解压和放置

Obsidian vault 只是包含文本文件的本地文件夹。
1. 将下载的 ZIP 文件移动到您打算存储笔记的硬盘上的永久位置（例如，`Documents/Obsidian_Vaults`）。
2. 解压 ZIP 文件。这将创建一个标准系统文件夹。
3. **关键检查：** 确保您的操作系统正在显示隐藏文件。打开解压后的文件夹，并验证其中是否存在名为 `.obsidian` 的隐藏文件夹。此隐藏目录包含由工具包创建者建立的所有设置、热键和插件配置。如果此文件夹缺失，则您只下载了空文本文件，而不是实际的 vault 设置。

### 第 2 步：在 Obsidian 中打开 Vault

1. 启动 Obsidian 应用程序。
2. 在 vault 选择窗口中，单击“打开文件夹作为 vault”旁边的 **打开** 按钮。
3. 导航到您刚刚解压的文件夹并选择它。
4. Obsidian 将加载该文件夹。如果提示您信任作者并启用插件，您可以这样做，前提是您信任下载的来源。由于 vault 只是文本文件，因此风险最小，除非 vault 包含可执行脚本（标准 starter kit 不包含）。

### 第 3 步：验证配置

在编写第一篇笔记之前，请验证 starter kit 的设置是否已正确加载：
*   打开“设置”>“文件和链接”。确保“新笔记的默认位置”指向正确的 Inbox 或 Fleeting Notes 文件夹。
*   检查“附件文件夹路径”以确保图像路由到 Attachments 目录。
*   打开“设置”>“核心插件”并验证 Templates 是否已打开，并且“模板文件夹位置”是否正确指向指定的模板目录。

## 实用建议：自定义您的 Starter Kit

下载的 starter kit 是一个基础，而不是一个紧身衣。一旦您了解了基本的机制，您必须调整 vault 以适应您特定的研究或写作需求。

### 根据您的 Workflow 调整属性

Starter kit 中的默认 YAML frontmatter 可能无法捕获与您的职业相关的数据点。如果您是学者，您可能希望在您的 Literature Note 模板中添加 `DOI`、`Journal` 和 `Peer Reviewed` 等属性。如果您是小说作家，您可能会将它们替换为 `Character`、`Location` 和 `Plot Arc`。

使用 Obsidian 内置的 Properties 界面来标准化这些添加。frontmatter 的一致性可确保您的 vault 在扩展时仍可搜索和过滤。

### 定义您的标签本体论

Zettelkasten 中的标签应该代表广泛的主题或完成状态，而不是超特定的关键词。笔记之间的链接起着特定关键词的作用。

审查您下载的工具包中提供的默认标签。一个常见且高效的标签系统包括状态指示器：
*   `#status/seed` - 需要开发的未完成思想。
*   `#status/incubating` - 您正在积极研究或思考的笔记。
*   `#status/evergreen` - 已完成的、高度链接的 permanent note。

这种 Workflow 标签可防止您的 vault 成为半成品想法的坟墓。您可以轻松单击 `#status/seed` 标签，以查看在下一次处理会话中确切需要您注意的笔记。

### 过度结构化的危险

新用户下载 starter kit 后最常见的错误是立即添加更多文件夹。Zettelkasten 方法在扁平层级结构中蓬勃发展。不要创建像 `Permanent Notes / Technology / Software / Obsidian` 这样的嵌套文件夹。

相反，将所有 permanent notes 放入单个 `02 - Permanent Notes` 目录中，并完全依赖双向链接（使用 `[[笔记名称]]` 语法）和标签来创建结构。让结构通过连接有机地出现，而不是自上而下地强加僵硬的归档系统。僵硬的文件夹结构最终会崩溃，因为概念自然会跨越多个类别。

## 构建每日笔记集成

许多现代 Obsidian Zettelkasten Workflow 都集成了 Daily Note 系统。这充当了最终的 Inbox。如果您的下载 starter kit 包含 Daily Notes 配置，它通常作为捕获零散思想的捕获点。

一个功能性的 Daily Note 模板可能如下所示：

```markdown

当您全天有想法时，将其记录在“Fleeting Thoughts”下。在一天结束时，或在专门的处理块期间，您会回顾此部分。如果某个想法有价值，您将其提取到自己的独立笔记中，将该新笔记移动到 Inbox 或直接移动到 Permanent Notes，并将 Daily Note 中的文本替换为指向新文件的链接。这确保您的每日笔记充当您在给定日期思考内容的索引，而不会将实际知识困在按时间顺序排列的文件中。

## 常见问题

### 我需要为 Obsidian Zettelkasten starter kit 付费吗？
不需要。虽然一些创建者在 Patreon 或 Gumroad 等平台上提供高级的、高度定制的 vault，但 GitHub 和官方 Obsidian 社区论坛上有大量优秀的免费 starter kit 可用。Zettelkasten 的基本机制可以轻松通过免费的开源配置实现。

### 下载的 vault 会覆盖我现有的 Obsidian 笔记吗？
不会，除非您将 ZIP 文件直接解压到您现有的 vault 目录中。Obsidian 将每个文件夹视为一个独立的 vault。您可以在不同的窗口中同时打开旧 vault 和新的 starter kit，从而逐步将旧笔记迁移到新结构中。

### 如果创建者发布了新版本，我如何更新 starter kit？
Starter kit 不是软件应用程序；它们只是包含文本文件和设置的文件夹。如果创建者发布更新，您不能简单地“点击更新”。您需要下载新的 ZIP 文件，查看他们对模板或 `.obsidian` 设置文件夹所做的更改，然后手动将这些更改应用到您现有的活动 vault，以避免覆盖您自己的笔记。

### 我应该使用文件夹还是标签来组织我的 permanent notes？
在一个纯粹的 Zettelkasten 系统中，您应该完全依赖链接和标签。所有 permanent notes 理想情况下都应该位于一个单一的、扁平的文件夹中。文件夹是僵化的，并且只允许笔记存在于一个位置。链接和标签允许笔记同时存在于多个上下文中，这是网络化思想的核心哲学。

### 为什么有些 starter kit 使用随机数字作为文件名？
这是 Luhmann ID 方法（例如，`202605071430.md`），由 Zettelkasten 的发明者创建。它确保每个文件都具有永久唯一的标识符，防止在您创建两个标题相似的笔记时发生文件名冲突。虽然有效，但许多现代 Obsidian 用户更喜欢自然语言标题（例如，`Obsidian scaling limitations.md`），以在 Graph View 中获得更好的可读性，并依赖 Obsidian 的内部数据库来管理链接。
